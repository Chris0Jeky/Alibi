# Lantern table editable pilot — 12 October 2026

**Version 1 study.** The owner found this below the requested pictorial quality bar. It remains unchanged for comparison with [material study 02](quality-02/README.md). Neither version is finished or production-accepted art.

`lantern-counter-vignette.svg` is original native SVG geometry (800×800, ten editable named layers). An engraved brass lantern, sage branch, petrol/ivory counters, tea and stationery share the existing warm ivory/petrol/sage/brass direction. `review.html` compares it directly with #525's painted Lantern Duel derivative. The vector finish is intentionally cleaner; the existing painted originals are preserved.

![Individual 800×800 Chromium preview of the editable vector master](lantern-counter-vignette-preview.png)

This PNG is a review derivative. The SVG remains the editable master and stays separate from runtime.

Actual Chromium pixels were inspected at 390 and 1440 widths. Cup placement and an out-of-bounds grain detail were corrected. The SVG has no image embedding, tracing, external content, animation or script. The source review page offers explicit restrained motion with pause, reduced-motion, document visibility and IntersectionObserver handling. This remains a proposed source alternative, outside runtime and precache.

## First painting integration candidate

This branch imports #525's four source commits and registers all sixteen masters plus their 32 derivatives. Only welcome desk, Lantern Duel and Pocket Borough use existing optional verified enhancement delivery, at 320px. Their combined optional bytes are 80,960. Thirteen other paintings remain proposed/source-only. All masters and larger derivatives stay outside release/precache. Meaningful envelope/tea, lantern/counter and borough SVGs provide complete fallbacks.

The eight-slot cache and 1 MiB/image bound are unchanged. It cannot promise all sixteen paintings offline; collisions can evict optional detail. Startup and shell ceilings are unchanged and near capacity. This tree does not combine #521; that combined candidate still needs budget/tests/browser qualification. Save IDs, revisions, labels, game rules and independent controls remain intact.
