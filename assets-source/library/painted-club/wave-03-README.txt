Four original decorative collection vignettes: salt-observatory, copper-conservatory, nocturne-gallery, winter-post-office. These match the existing collection names and atmospheric descriptions in Alibi. They do not depict a puzzle solution, a real site, or an existing credited museum artwork. In particular, the small coastal paintings inside the gallery frames are newly generated imagined scenes.
