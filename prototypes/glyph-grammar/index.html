The rules of this small language

Each workshop mark names a different workshop, each tool mark a different tool, and each relation mark a different relation. A mark keeps its meaning. An unmarked tool means one. Split chevron marks either one or two.

A message has either workshop · relation · tool phrase, or tool phrase · relation · workshop. Within the tool phrase, the count mark goes before or after the tool. Moving the phrase does not reverse it. These are the only rules considered.
