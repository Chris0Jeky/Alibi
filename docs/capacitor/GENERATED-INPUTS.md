# Generated native inputs: review repairs for PR #485

Refs #120, #126, #132 and #133. This extends the existing plugin-free Capacitor host,
not the application runtime or save model.

## Contract

The first native sync audit checked copied web bytes and plugin JSON but did not check
executable generated Gradle scripts. An empty plugin registry does not prevent a generated
script from adding a local project or Java dependency. `native:sync` and its `--check` path
now enforce reviewed SHA-256 identities for all four generated Gradle scripts and the generated
Cordova-module manifest. Only CRLF to LF normalization is allowed. Paths, Java targets, version
defaults, hooks and manifest declarations cannot change silently. Missing files, symlinks
(including parent aliases), oversized inputs and unexpected module Java/JAR/resource/configuration
files are rejected before Gradle runs.

The generated module retains its reviewed source inventory. Its `build/` outputs are allowed so
the same check can run after compilation; pinned scripts do not treat that directory as an extra
source or local-library location. The actual-APK audit remains a separate check, not a substitute
for the exact generated manifest: its allowlists are not an exhaustive manifest grammar.

## Provenance

Fixtures reproduce plugin-free Capacitor CLI 8.5.2 output. Settings, app script and variables
come from `installGradlePlugins` / `handleCordovaPluginsGradle` in the
[pinned CLI source](https://github.com/ionic-team/capacitor/blob/8.5.2/cli/src/android/update.ts).
The module script derives from the
[pinned template](https://github.com/ionic-team/capacitor/blob/8.5.2/capacitor-cordova-android-plugins/build.gradle),
with the CLI's empty-dependency substitution and explicit variables-file import, as confirmed
against retained CI in [GENERATED-INPUT-RECONCILIATION.md](GENERATED-INPUT-RECONCILIATION.md).

The manifest is generated by `writeCordovaAndroidManifest`, not merely copied from the template.
The [8.5.2 implementation](https://github.com/ionic-team/capacitor/blob/8.5.2/cli/src/cordova.ts),
Git blob `343d1695aa64e947be2b9e9a949c8958365524c1`, emits empty root/application arrays and no
cleartext override for this configuration. The 210-byte fixture preserves its exact spacing and
lack of terminal newline, SHA-256 `2e3e383475f0e6cb76f0a7b46017a546663fba8e5bd1ef2a537412afac2ee9b5`.
The fixture directory retains the upstream MIT licence. No upstream version is upgraded. Future
plugins or CLI updates require explicit policy/fixture review rather than automatic trust.

## Manifest review regression and verification

Review discussion_r4139064435 showed that inventory-only checking accepted changed package
visibility, hardware features and private components. Four focused mutation tests failed on the
previous policy and pass after pinning the manifest. The generic suite now includes manifest
injection, removal and symlink checks. Both generated-input suites pass locally: 27 tests,
zero failures/skips, using the recovered exact scripts and policy implementation. The ordinary
repository test glob includes the new dedicated suite; native CI also runs the expanded generic
suite before actual sync.

Fresh CLI generation, formatting, full repository verification, strict native compilation,
APK inspection and emulator controls remain exact-head CI gates. The canonical Maven verification
file is still unchanged; [METADATA-REPAIR.md](METADATA-REPAIR.md) contains the reviewed checksum
patch. Do not disable verification to obtain a green build. Physical Android, TalkBack, publisher
identity, signing and Play publication remain owner/device gates in HUMAN_TODO.md.
