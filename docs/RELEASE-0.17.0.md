# 0.17.0: Mirror Ledger, Timeline Desk and escape-room previews

## Publication pending

Alibi 0.17.0 remains unpublished. This provisional record covers changes merged through
`e8a3430663c3d784f761024c7bcc0f44809c4009` on 11 November 2026. The release preparation
sets the package to 0.17.0; the published site remains on 0.16.0.

The candidate adds Mirror Ledger to the experimental Eclipse Lab, introduces the
experimental Timeline Desk, and opens six untimed, experimental escape rooms in Wrenmere
Castle. Escape progress lasts until reload or close. It also improves phone completion
navigation and the labelling and keyboard focus of Castle case controls.

Pulseboard [#264](https://github.com/Chris0Jeky/Pulseboard/pull/264) registered the release
history. Its [automatic deployment](https://github.com/Chris0Jeky/Pulseboard/actions/runs/43083778431)
passed, and the collector reported ready, schema 6, with Alibi admitted.

The [deployment procedure](DEPLOYMENT.md) governs release verification and publication.
The release source SHA, build ID and Cloudflare receipt will be recorded after those steps.
