# Provenance and licence boundaries

Original extension code, procedural geometry, companion artwork, copy and badge designs were authored for this prototype. No new repository-wide reuse licence is selected on the owner's behalf. Retain the owner's existing licensing decision.

`assets/quiet-town.webp` comes from the owner's current Alibi release; retain its existing asset provenance.

`assets/kenney-keeper.png` is Kenney's Castle Kit sprite, CC0, retrieved from the ETdoFresh community mirror. Original author/licence: https://kenney.nl/assets/castle-kit . Exact Git blob SHA: e453368ed178fec5151f15f9f310166ee645501c. No Kenney logo is used.

Museum images are optional download targets and are not present in the baseline asset directory. The acquisition tool records individual rights, sources and hashes. Full Kenney model packs are recommendations, not bundled downloads. No font files or user-supplied reference screenshots are included.
