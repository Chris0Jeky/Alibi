## Completion rule

Each implementation records source tree, tests run, CI head, reviewer identity and remaining gates. Local self-review is not independent review. A case source may pass structure while its conclusion is unsupported. A playable memory-only preview may pass browser tests while host persistence is entirely absent. Keep those distinctions in issue closure and PR descriptions.
