## Status vocabulary

**Observed** means inspected in this baseline or live repository. **Corroborated** means a named primary source supports the narrow factual statement. **Proposed** means a design recommendation, not a shipped capability. **Unvalidated** means an empirical question remains. A structural validator pass is not a proof of clue fairness, mathematical uniqueness or human enjoyment.

The delivery PRs must record their own current source SHA and evidence. This document is not a blanket acceptance of future implementations. Preserve existing independent-review, head-aging and CI gates. No paid generation, purchased assets, account setup or production launch is implied.
