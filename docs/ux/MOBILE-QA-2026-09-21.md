# Phone play and shell QA

Base: `35b5ba39d468a9010afcfa5e0ae6a16ce92a7e44`, the current published main after the
Block Cabinet and Games Room merges. The candidate build is `971b3d96ac94`.
Source: player QA issues #208–#218 and design follow-ups #222/#223. The QA author's local
Windows screenshots were not available here; failures were reproduced independently.

## Delivered behavior

- Play opens with the puzzle heading and board. Optional story, room controls and assistant
  choices follow in one native disclosure, in DOM and keyboard order. Its open state and
  focused controls survive rerenders. Evidence remains outside that disclosure.
- A small screen scrolls to the board only on entry or lesson dismissal when it would
  otherwise extend below the visible area. Editing/selection does not auto-scroll.
- Bridges' dedicated renderer now respects zoom: both the map and island targets enlarge,
  with overflow contained inside the map. Normal size restores without altering the save.
- Header/player/close controls have real 44px minimum hit areas. Settings retain a small
  visible switch inside a 52×44 input; keyboard and label semantics remain native.
- Route changes close their modal before old-save awaits, without marking a lesson complete.
  Native `showModal()` supplies background inertness. Tab boundaries cycle explicitly;
  lesson replacement preserves a matching control or focuses its heading. Closing restores
  the opener when it still exists, otherwise the current main landmark.
- Navigation counts include units; card buttons name title/family/difficulty/size/status
  instead of reading decorative preview digits. Favorites remain separate controls.
- Mobile tabs use short visible labels and full accessible names. Edition labels have an
  11px floor. Search metadata uses the durable lower bound “300+”; the manifest remains
  generated from the actual catalogue.

## Evidence and reproduction

`python tests/browser_mobile_qa.py` runs against `ALIBI_URL` (default port 8787). It is wired
into required CI and uploads viewport screenshots plus `board-metrics.json`. Coverage:
320×568, 360×800, 390×844, 430×932, 844×390; zoom/normal-size; outside-track switch taps;
no-move/no-scroll selection; context disclosure after assistant changes; Tab/Shift+Tab;
route leave/reentry; Escape; lesson-step focus; desktop accessible names; phone nav overflow.

`node --test tests/metadata.test.cjs` guards the stable search description against the official
catalogue. `node tools/assets/catalogue.cjs` refreshes the existing source fingerprint ledger.

The optional `ALIBI_QA_HTML` environment variable supports an isolated document fixture for
local debugging only. It must not replace the real-origin CI invocation. The local run used the
repository's pinned dependency set and a static HTTP server on port 8793. No physical phone,
installed-PWA, TalkBack or real device-save claim follows from that run.
